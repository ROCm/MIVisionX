# Utilities

MIVisionX provides the following command-line utility:

## [RunVX](runvx/README.md#amd-runvx)

A command-line tool that executes OpenVX graphs described in GDF (Graph Description Format) text files. It encapsulates the routine OpenVX setup calls, enables rapid prototyping without writing C code, and supports file I/O, data comparison, image display (with OpenCV), and performance profiling.

See the [RunVX README](runvx/README.md) for the full command reference and GDF syntax.

******************************************
MIVisionX documentation
******************************************

MIVisionX is a streamlined computer vision toolkit built around AMD's implementation of `Khronos OpenVX <https://www.khronos.org/openvx/>`_ 1.3. As of the 4.0.0 release, it ships the AMD OpenVX engine, the AMD RPP OpenVX extension, and the RunVX graph executor, supporting the ``CPU``, ``HIP``, and ``OpenCL`` backends. The toolkit is used for rapid prototyping and execution of optimized computer vision workloads on a wide range of computer hardware, including small embedded CPUs, APUs, and discrete GPUs.

The MIVisionX public repository is located at `https://github.com/ROCm/MIVisionX <https://github.com/ROCm/MIVisionX>`_.
